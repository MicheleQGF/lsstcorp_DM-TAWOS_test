# lsstcorp_DM-TAWOS_test
This is a data analysis of data extracted from Jira from the TAWOS dataset
Dataset: tawos-csv-clean.csv from https://www.kaggle.com/datasets/rachetkhanal/tawos-csv-clean?resource=download 

Después de elegir el proyecto, extraí un dataset con sólo el proyecto de Lsstcorp Data Management con 10631 registros

Análisis de Desempeño de LsstCorp Data Managment
📂 Contenido del repositorio

    TAWOS_Project_Test.ipynb → Notebook principal con limpieza y extracción de la tabla utilizada
✪ Etapas Realizadas:

    Carga y exploración del dataset
    Elección del proyecto por porcentaje de datos registrados, Lsstcorp Management contenía más o menos 80% de los datos en todas las columnas clave
    Cálculo de SPI y CPI anuales

🧠 Objetivo del análisis

    Identificar un proyecto real en una base de datos de Jira
    Analizar el desempeño del proyecto a lo largo de los 7 años de duración mediante el cálculo de SPI y CPI y visualizaciones
    Visualizaciones con Tableau del análisis
    Generar insights sobre las conclusiones del análisis
