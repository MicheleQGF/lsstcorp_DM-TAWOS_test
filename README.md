# lsstcorp_DM-TAWOS_test
This is a data analysis of data extracted from Jira from the TAWOS dataset
Dataset: tawos-csv-clean.csv from https://www.kaggle.com/datasets/rachetkhanal/tawos-csv-clean?resource=download 

After choosing the project, I extracted a dataset with only the Lsstcorp Data Management project with 10,631 records.

Performance Analysis of LsstCorp Data Management
📂 Repository Content

    TAWOS_Project_Test.ipynb → Main notebook with cleaning and extraction of the table used
✪ Stages Performed:

    Loading and exploration of the dataset
    Project choice by percentage of recorded data; Lsstcorp Management contained roughly 80% of the data in all key columns
    Calculation of annual SPI and CPI

▶ How to open the notebook in Google Colab

Click on the following button: [ Open In Colab](https://colab.research.google.com/drive/1C1NREiwP9HaEUCOqghsFYUXjKVjLAJ9r?usp=sharing)

Or:

    Open the .ipynb file on GitHub
    Click on Open in Colab

📘 How to reproduce the analysis

    Open TAWOS_Project_Test.ipynb
    Run the cells in order (the dataset path may need to be changed because it is relative)
    

🧠 Objective of the analysis

    Identify a real project within a Jira database
    Analyze the project's performance over its 7-year duration through the calculation of SPI and CPI, and visualizations
    Tableau visualizations of the analysis
    Generate insights on the conclusions of the analysis
